Why “Plimsoll”?

A Plimsoll line is the mark on a ship's hull that shows how far it can safely be loaded. Above the line, you're fine. Below it, you're in trouble. These tools do the same for your project: they show you where the limits are, so you find out before your players do.

Plimsoll Tools is run by an indie game programmer from northern Germany. The Unity tools started as problems in real production work on commercial Unity projects.
