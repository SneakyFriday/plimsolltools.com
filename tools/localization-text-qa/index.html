Localization Text QA

Every language, every text, one scan.

This tool is in development. The documentation below grows with it.

What it checks

Text overflow
Measures every localized TextMeshPro text in every language against its box, including texts that only fit because Auto Size shrank them to the minimum.
Missing glyphs
Checks every character of every translation against the font that will draw it, through TextMeshPro's real fallback chain, including fonts that change per language.
Placeholder mismatches
Compares smart-string placeholders between languages and flags extra, missing or changed placeholders before they break at runtime.

Requirements

  • Unity 6
  • Unity Localization package
  • TextMeshPro (UI Toolkit text and legacy UI Text are not checked)

Safety and known limits

  • The scan never saves or dirties your scenes, prefabs, string tables or font assets.
  • Dynamic font atlases may grow in memory during a scan, exactly as when TextMeshPro renders text in the Scene view.
  • Dynamic OS fonts are reported as not checked: they depend on the fonts installed on the player's device.
  • Scanning is blocked while the Font Asset Creator is open.
